WARNING: Authorised access only.

VERIFICATION COMMANDS — R2 DURBAN

1. Check interface status and IP addresses:
show ip interface brief

2. Check DHCP pools:
show ip dhcp pool

3. Check assigned DHCP addresses:
show ip dhcp binding

4. Check OSPF neighbours:
show ip ospf neighbor

5. Check learned routes:
show ip route ospf

6. Check guest security ACL:
show access-lists DBN-GUEST-FILTER

7. Check SSH status:
show ip ssh

8. Test connectivity:
ping 10.255.0.1
ping 10.10.20.1
ping 10.30.210.1
