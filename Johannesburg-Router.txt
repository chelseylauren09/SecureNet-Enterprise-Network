4. GUEST ACCESS CONTROL
=======================

ACL Name: JHB-GUEST-FILTER
Applied inbound to GigabitEthernet0/0.60

Purpose:
Restricts guest network access to internal departmental,
server, management and other branch networks.

The ACL permits DHCP requests, denies specified internal
destinations and permits other traffic according to the
configured rules.

6. LOGIN WARNING BANNER
=======================

WARNING: Authorised access only.

VERIFICATION COMMANDS — R1 JOHANNESBURG

1. Check interface status and IP addresses:
show ip interface brief

2. Check VLAN gateway subinterfaces:
show running-config

3. Check DHCP pools:
show ip dhcp pool

4. Check assigned DHCP addresses:
show ip dhcp binding

5. Check OSPF neighbours:
show ip ospf neighbor

6. Check learned routes:
show ip route ospf

7. Check guest security ACL:
show access-lists JHB-GUEST-FILTER

8. Check SSH status:
show ip ssh

9. Check login and SSH settings:
show running-config

10. Test connectivity:
ping 10.20.10.1
ping 10.30.210.1
ping 10.10.50.20
